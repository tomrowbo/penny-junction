# Penny for S-Bank — brand design

## Intent

Present the Junction prototype as **Penny**, a standalone personal economic trainer designed for S-Bank. It should use a Finnish banking-inspired design system without copying S-mobiili so closely that the prototype appears to be an official S-Bank release.

## Chosen approach

Use a co-branded hierarchy: **Penny** is always the primary product name; **for S-Bank** is a smaller partnership descriptor. Penny is a standalone app with its own navigation, while its visual system demonstrates that the concept could sit naturally beside S-Bank's products.

Alternatives considered:

- A Penny tab inside a replica banking shell would demonstrate embedding but make the prototype look more official than intended.
- A near-exact S-mobiili replica would demonstrate fit but overstate official status and make Penny feel like a feature name rather than the product concept.

## Interface changes

- Change the installed app display name from `S-mobiili Concept` to `Penny`.
- Replace the login's `S-MOBIILI` identity with a Penny-first lockup: `Penny` with smaller `for S-Bank` text.
- Keep the restrained green palette, rounded cards, information density and native system typography. Do not import a proprietary S-Bank font unless it is explicitly licensed and supplied.
- Replace the replica banking shell with Penny's own three-tab navigation: **Penny**, **Accounts**, and **Me**.
- Use the existing Penny goals view as the home tab, the consolidated multi-bank account/transaction view as Accounts, and a Penny-specific data/privacy/about view as Me.
- Present S-Bank names and marks only where they identify the challenge partner, connected institution, official synthetic dataset or proposed host application.
- Rename internal user-facing “S-mobiili concept” copy to neutral “banking concept” or “Penny concept” wording.
- Add a discreet concept disclosure on the login/about surface: `Junction concept using synthetic S-Bank data`.

## Non-goals

- Do not remove S-Bank from account/data-source labels.
- Do not redesign the working financial coaching flow or backend integration.
- Do not alter backend dataset provenance, calculations or API contracts.
- Do not claim Penny is an official production S-Bank application.

## Success criteria

- The home-screen app name and first screen read as Penny.
- No S-Etukortti, wallet, receipt or replica S-mobiili service appears in Penny's primary navigation.
- A judge understands immediately that Penny is proposed for S-Bank.
- The interface still feels plausible beside a Finnish banking app.
- No screen presents the prototype itself as S-mobiili or as an official released S-Bank product.
